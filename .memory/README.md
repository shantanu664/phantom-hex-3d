# Memory bank - phantom-hex-3d

Committed working memory for this project. It exists so that a dropped SSH
session, a closed terminal or a rebooted VPS never costs you the thread of
what you were doing.

| File | What it is | Who writes it |
|---|---|---|
| STATE.md | Current focus, work in flight, next steps | you, and Claude |
| JOURNAL.md | Append-only dated log | mem note |
| SNAPSHOT.md | Branch, HEAD, uncommitted files, stashes | generated by mem snap |
| wip/ | Explicit patches of uncommitted work | mem wip |

Read STATE.md first when picking this project back up.
